# InnerBloom 🌸

InnerBloom is a full-stack wellness and period-tracking web application developed in 2025. It helps users securely track their menstrual cycles, monitor period history, and access personalized cycle insights through an intuitive dashboard.

## Features

* Secure User Registration & Login
* JWT-Based Authentication
* Password Hashing with bcrypt
* Forgot Password & Reset Password via Email
* Protected Routes
* User Profile Management
* Geolocation Integration
* Period Tracking & History
* Cycle Statistics & Insights Dashboard
* Responsive Design for Mobile, Tablet, and Desktop

## Tech Stack

## Installation

1. Clone the repository

```bash
git clone [https://github.com/amisha-ctrl/innerbloom.git](https://github.com/amisha-ctrl/innerbloom-period-tracker.git)
```

2. Navigate to the project directory

```bash
cd innerbloom
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file and configure the required environment variables.

5. Start the server

```bash
npm run dev
```

or

```bash
node server.js
```

6. Open your browser

```bash
http://localhost:5000
```
